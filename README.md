## 📣 갤러리 직관 & 응원 에티켓 (Gallery Guide)

임진희 프로가 최고의 샷을 날릴 수 있도록 함께 지켜주세요!

1. **Quiet Please!**
   - 어드레스 자세에 들어가거나 샷을 준비할 때는 발소리와 숨소리도 낮춰주세요.
   - 휴대전화는 반드시 **무음(진동 X)** 모드로 전환해 주세요.
2. **카메라 촬영 주의**
   - 백스윙과 임팩트 순간에는 셔터음 및 플래시 촬영이 엄격히 금지됩니다.
3. **홀 이동 매너**
   - 선수가 티샷이나 퍼팅을 완전히 마친 후 다음 홀로 이동해 주세요.
4. **따뜻한 환호와 박수**
   - 굿샷에는 아낌없는 박수와 환호를, 아쉬운 순간에는 따뜻한 격려를 보내주세요!
